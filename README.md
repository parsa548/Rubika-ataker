# Rubika Manager

سیستم مدیریت پیام‌ها و چت‌ها با پایتون

## امکانات فعلی

- ذخیره پیام‌ها در دیتابیس SQLite
- افزودن و حذف پیام‌ها
- نمایش فهرست پیام‌ها
- مدیریت وضعیت چت‌ها
- تنظیم بازه زمانی هر چت
- مدیریت وظایف ناهمگام

## پیش‌نیازها

- Python 3.10 یا بالاتر

## نصب وابستگی‌ها

```bash
pip install -r requirements.txt
